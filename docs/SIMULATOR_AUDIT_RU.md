# Аудит симулятора, 10 сентября 2026

Требование «идеально повторяет реальную игру» для всей Clash Royale пока не
выполнено и не может считаться выполненным без видеопроверок каждой механики.
Репозиторий теперь разделяет два разных уровня готовности вместо смешения их
результатов.

## Текущее состояние

| Компонент | Статус |
|---|---|
| Общий JSON/CSV постановок | Работает; строгие 20-Гц времена, обе стороны, мировые и player-local координаты |
| Rudy runtime | Backend по умолчанию; подключён к тому же входу и автономному HTML |
| Ядро Rudy: Hog + Cannon + Princess Tower | Строгий видеотест проходит |
| PRIMARY с соседним боем | Диагностический сценарий с Ice Golem и Hunter; не входит в чистый core gate |
| cr-bot runtime | 109 исполняемых обычных карт, checkpoint и восстановление |
| Все карты/эволюции/чемпионы/уровни | Не верифицированы относительно реальной игры |

## Видеопроверенный Rudy milestone

Закреплён Rudy `nguiaSoren/clash-royale-suite@050275d70b84614953877e8075dc4b8ba907c67f`.
Патчи фиксируют арену 18×32, scale 1000 units/tile, центры башен и зданий,
скорости, edge-to-edge range, First Hit Speed, lifetime decay, deploy-time pull,
обычные (не автоматические Evo) карты и общий pipeline снарядов башен/пушки.

Строгий gate включает:

- Solo Hog → Princess Tower: 7/7 ударов, 317 урона, первый удар и средний
  интервал в допуске;
- d03 SECONDARY: три удара Хога, смерть пушки и Хога в допуске 0,10 с;
- d02 CROSSDEMO: два удара, смерть пушки и Хога в допуске 0,10 с.

PRIMARY имеет наблюдаемые времена 4,30 / 5,90 / 7,50 с для ударов, 7,50 с для
смерти пушки и 8,70 с для смерти Хога. На том же фрагменте Ice Golem и Hunter
удерживают левую Princess Tower, поэтому изолированный вход Хог+Пушка не является
полным состоянием боя. В regression эти тела добавляются через
`seed_troop_state`; их непроверенный исходящий урон отключён.

## Почему ранний cr-bot результат расходился

Первые тесты запускали cr-bot, хотя последние физические поправки делались в
Rudy. Дополнительно использовался старый набор из восьми карт вместо roster на
109 карт. После выбора roster Хог получил river jump, но timing и путь всё равно
не совпали с видео. Поэтому cr-bot сохранён для широкой функциональной проверки,
а не используется как доказательство точности.

В cr-bot-профиле `hog-bridge-first-hit-v1` первый таймер Хога начинается только
после входа в дальность. Это локальная экспериментальная гипотеза cr-bot. Она не
заменяет и не изменяет видеоподтверждённую модель Rudy, где Хог в PRIMARY
пересекает открытую часть реки как jump-capable troop.

## Контракт пользовательского Rudy runtime

`play_observed_card()` принимает постановку, уже подтверждённую источником. Он
временно обеспечивает доступность карты и эликсира, после чего вызывает штатный
Rudy `play_card`: deployment, formation, spell, target acquisition и дальнейшая
физика не обходятся. На одну сторону допускается не более восьми различных карт,
что соответствует реальной колоде.

Workflow после сборки wheel запускает пользовательский `simulate.py` на d03
SECONDARY и d02 CROSSDEMO. Поэтому строгий gate проверяет не только отдельный
диагностический скрипт, но и реальный путь JSON → runtime → events → comparator.

## Исправления replay runtime

- горизонт больше не заканчивается на постановке и не зацикливается после
  terminal state;
- одинаковый tick двух сторон исполняется одной физической границей, два
  действия одной стороны отклоняются;
- отсутствующая колода в `placements` не воспринимается как ошибочная пустая
  колода;
- `world_mtile` и `player_cells` преобразуются один раз без скрытого округления;
- отказ карты сохраняет исходный индекс события и возвращает CLI code 2;
- сравнение использует события фактического урона, включая смертельный удар;
- автономный `replay.html` содержит собственные данные и работает без сервера;
- checkpoint cr-bot включает таймеры, снаряды, RNG и проверяемый state hash.

## Оставшиеся границы

Rudy пока не сериализует полное внутреннее состояние, поэтому его checkpoint
явно невозобновляемый. cr-bot checkpoint не совместим с Rudy. Произвольные уровни,
другие Tower Troops, точная высота прыжка, эволюции и способности чемпионов требуют
отдельных эталонов. «Карта исполняется без падения» не означает «карта совпадает с
Clash Royale».

Следующий правильный шаг — добавлять по одному независимому видео-сценарию на
новую механику и принимать изменение только после прохождения уже существующего
core gate.
