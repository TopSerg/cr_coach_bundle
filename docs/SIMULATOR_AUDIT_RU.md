# Аудит, 10 сентября 2026

Исходный commit: `1201e1a0c8448e1ac026ce58ee4203ce96476017`.
Требование «идеально повторяет реальную игру» пока не выполнено. Реализован рабочий
воспроизводимый запуск по постановкам и исправлены конкретные ошибки; эквивалентность
закрытому игровому движку не доказана.

## Выявленные проблемы

1. Последние исправления движения и атак относились к Rudy, а тест PRIMARY запускал
   cr-bot. Изменения одного backend не влияли на другой.
2. `BattleEngine()` использовал набор `2026-08-04` из 8 карт. В той же закреплённой
   версии есть `2026-08-04-roster` из 109 карт с другими параметрами и river_jump Хога.
   Новый runtime выбирает расширенный набор явно.
3. Старый исполнитель останавливался через тик после последней постановки, часто
   до боя. После завершения матча `advance_to` мог зациклиться, поскольку upstream
   `step()` больше не увеличивал тик. Теперь есть горизонт и остановка на terminal.
4. Отложенный отказ постановки мог приписываться следующему событию. Теперь группа
   действий коммитится сразу целиком, отказ содержит исходный индекс.
5. Сравнение HP через `zip` списков допускало неверное сопоставление разных тиков и
   могло пропускать обрезанный trace. Исправлено сопоставление по времени и покрытию.
6. Тест comparator solo использовал старую временную привязку и уменьшал HP другой
   башни. Исправлена фикстура без изменения эталонной записи.
7. PRIMARY считал удары по `attack_count` и текущей цели после death resolution;
   смертельный удар мог потеряться. Новый comparator читает `damage_applied`.

## Поправка маршрута

`CoachBattleEngine`, профиль `hog-bridge-first-hit-v1`, использует обычную наземную
навигацию к Crown Tower, пока Хог пересекает реку. Перетягивание обычным зданием
сохраняет upstream river-jump поведение. Это правило применяется по типу юнита/цели,
а не по имени видео или заданному времени. Закреплённый backend и правила не изменяются.
Версия поправки записывается в report/checkpoint и проверяется при продолжении.
Таймер первого удара Хога теперь отсчитывается в дальности атаки; имеющееся в roster значение 0,6 с не изменяется. Это проверено по чистому SECONDARY. Jump-duration и урон не подгоняются под PRIMARY.

## Границы поддержки

109 карт проверяются на выполнение постановки против живого соперника, 180 тиков
физики, инварианты и восстановление состояния. Это не 109 видео-верифицированных карт.
Только уровень 11, центры клеток, шаг 20 Гц и закреплённый августовский баланс.
Эволюции, способности чемпионов, другие Tower Troops и произвольные уровни не покрыты.
Upstream содержит непроверенные механики в `simulator/UNKNOWN_BEHAVIORS.md`;
неопределённости выбранных карт включаются в отчёт.

Автономный HTML формируется без внешних ресурсов; синтаксис JavaScript проверен.
Автоматический браузер рабочей среды заблокировал localhost и file URL, поэтому
визуальная проверка здесь не завершена. Это ограничение проверки, не runtime-зависимость.

Дальнейшие поправки следует принимать по первому расхождению движения/цели/попадания
и проверять на независимом чистом эпизоде, а не только по смерти юнитов PRIMARY.
